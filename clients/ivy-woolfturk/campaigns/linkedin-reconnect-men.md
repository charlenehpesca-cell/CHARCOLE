# LinkedIn reconnect message — male connections

Outreach from Ivy's LinkedIn to male connections she hasn't messaged in 6+ months (or ever), asking them to pass A Liberated Life to a woman in their life.

## Rules (agreed 2026-11-07)

- **Audience:** men only, judged from first name (no gender field on LinkedIn). Ambiguous names (Alex, Jordan, Chris, Sam, Taylor, Jamie, etc.), initials-only names and anyone with she/her pronouns are skipped. No pre-send review.
- **Interaction = direct messages only.** Skip anyone whose LinkedIn thread with Ivy has a message dated within the last 6 months.
- **Never double-send:** skip any thread that already contains "A Liberated Life".
- **Pace:** ~20–25 per day to avoid LinkedIn restrictions.
- Greeting uses the person's first name ("Hi Jeffrey,"). Message text below, unchanged otherwise.

## Method

1. Pull connections via Ivy's signed-in LinkedIn in Chrome (sorted recently added).
2. Exclude names in her inbox with messages since May 7, 2026.
3. Filter to clearly male first names → 407 candidates as of 2026-11-07.
4. For each: open `linkedin.com/messaging/compose/?recipient=<profile id>`, check the thread's latest date and for "A Liberated Life", paste message, send, verify.

Really.
