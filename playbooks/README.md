# Playbooks

Reusable processes that work for any client: onboarding, content workflows, reporting, offboarding.

## How to add one

- One file per process, named like `client-onboarding.md`.
- Keep it generic: no client names or client data.
- Structure: **When to use**, **Steps**, **Checklist**, **Templates**.
