# CHARCOLE — Second Brain

Private notes repo shared by Obsidian (on my computer) and Claude (on every device). Everything syncs through GitHub.

## What lives where

| Path | What's in it |
| --- | --- |
| `AGENT.md` | Living constitution: how the agent works. Loaded every session. |
| `CLAUDE.md` | Rules, preferences and the routing map. |
| `MEMORY.md` | Cross-session index pointing to `memory/`. |
| `00_Resources/` | Shared references, including my voice principles. |
| `clients/_template/` | Copy this for every new client. |
| `clients/<name>/` | One folder per client, each with its own CLAUDE.md and MEMORY.md. |
| `personal/` | My own business: brand, offers, content, digital products. |
| `playbooks/` | Reusable processes for every client. |
| `00 - Inbox/` | Quick captures; new notes land here. Empty it weekly. |
| `10 - Projects/` | One note per active (non-client) project. |
| `20 - Areas/` | Ongoing responsibilities: Dev, Business, Learning. |
| `30 - Resources/` | Reference material and MOCs. Start at `Home.md`. |
| `40 - Archive/` | Done or inactive notes. |
| `50 - Zettelkasten/` | Permanent insights, one idea per note. |
| `Daily/` | Daily journal notes. |
| `Templates/` | Note templates (Daily, Project, Area, Resource, Zettel, Inbox Capture). |
| `Attachments/` | Images and files. |
| `rules/` | Safety, conventions, operations. |
| `skills/` | Checkpoint, session end, feedback, review proposals. |
| `governance/` | Proposals, learnings log, remaining TODOs. |
| `memory/` | User, feedback, project and reference memory. |

## Sync

- Obsidian Git plugin: auto commit-and-sync and auto pull every 5 minutes, pull on startup.
- Instant sync in Obsidian: Ctrl + P (Windows) → **Git: Pull** or **Git: Commit-and-sync**.
- Fallback: GitHub Desktop → Commit to main → Push origin.

Never store passwords, API keys or tokens here.
